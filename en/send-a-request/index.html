The WhatsApp message: the request has been received

Once the form is sent, a WhatsApp message saying that the request has been received goes to the phone number entered in it. After that it is clear that the form has arrived and the number was entered correctly.

We contact you at the same number about the job you requested, and in the conversation you discuss the job and its price. If the job first has to be looked at on site, there is the line “Visit on site and assessing the fault” (from €35). If water is leaking already, read the page emergency service.

The copy of the request and 90 days

A copy of the request is kept in the website’s storage so that it is not lost if the connection breaks for a moment; after 90 days the copy is deleted automatically. Who else processes the data and how to ask for it to be deleted is described in the privacy policy.

About the WhatsApp message and the request data

The WhatsApp message did not arrive. What should I check?

First, whether the phone number was entered correctly in the form, without extra digits. If there was a mistake in the number, send the form again with the correct number.

Which page is best for filling in the form?

Any. The form is the same on all pages; on a job or place page some of the fields are already filled in, and you can change them.
